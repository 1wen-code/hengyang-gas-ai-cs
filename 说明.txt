============================================================
  衡阳燃气AI客服智能体系构建 — 项目运行说明
============================================================

一、项目简介
------------------------------------------------------------
  本项目是一个基于 DeepSeek 大模型的燃气行业AI智能客服系统，
  采用 Flask + Router/Session/Handler 架构，
  实现FAQ智能问答、多轮对话、风险检测和自动工单等功能。

二、运行环境要求
------------------------------------------------------------
  - Python 3.9 或更高版本（推荐 3.11+）
  - Windows / macOS / Linux 均可
  - 需要稳定的网络连接（用于调用 DeepSeek API）

三、安装步骤
------------------------------------------------------------
  1. 解压本项目到任意目录
  2. 打开终端（CMD/PowerShell/终端），进入项目目录：
     cd 项目目录路径
  3. 安装依赖（只需执行一次）：
     pip install -r requirements.txt

四、配置步骤
------------------------------------------------------------
  1. 在项目根目录创建 .env 文件（或在 Render 环境变量中配置）
  2. 填入以下必需配置：
     DEEPSEEK_API_KEY=你的DeepSeek_API密钥
  3. 可选配置：
     ADMIN_PASSWORD=管理后台密码（默认 hygas0826）
     FLASK_DEBUG=True（开发模式）

五、启动方法
------------------------------------------------------------
  本地开发模式：
    python app.py
    浏览器打开 http://localhost:5000

  生产模式（Linux服务器）：
    gunicorn app:app --bind 0.0.0.0:5000

六、线上访问说明（重要！务必阅读）
------------------------------------------------------------
  线上地址：https://hengyang-gas-ai-cs.onrender.com
  管理后台：https://hengyang-gas-ai-cs.onrender.com/admin

  !! 首次访问/长时间未访问时，请耐心等待 30-60 秒 !!

  原因说明：
  本系统部署在 Render 免费版云平台上。Render 免费版具有
  "休眠机制"：如果 15 分钟内没有任何用户访问，服务器会
  自动进入休眠状态以节省资源。当再次有用户访问时，Render
  需要重新启动服务器（冷启动），这个过程通常需要 30-60 秒。

  正常现象：
  - 打开网页后看到 "Application Loading" 或 "Starting..."
  - 页面显示加载进度条或启动日志
  - 30-60 秒后自动进入聊天界面

  不是系统故障，只是服务器在"起床"。
  启动后即可正常使用，后续访问速度恢复正常。

  如果是本地部署（python app.py），则不受此影响。

十、常见问题
------------------------------------------------------------
  Q: 启动报错 ModuleNotFoundError
  A: 执行 pip install -r requirements.txt

  Q: AI不回复，日志报API错误
  A: 检查 .env 文件中 DEEPSEEK_API_KEY 是否正确配置

  Q: 管理后台工单为空
  A: 本地默认不持久化，触发danger模式后刷新页面查看

  Q: 网页打开是空白/加载失败
  A: 确认 python app.py 正在运行，终端无报错
